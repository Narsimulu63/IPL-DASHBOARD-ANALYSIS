# IPL-DASHBOARD-ANALYSIS
IPL Data Analysis Dashboard built using Python, Pandas, and Matplotlib to visualize team performance, player statistics, match results, and season insights through interactive charts and graphs.


FEAUTERS
IPL team performance analysis
Match-wise results visualization
Top run scorers analysis
Leading wicket takers analysis
Team win comparison charts
Season-wise performance trends
Data cleaning and preprocessing using Pandas
Visualizations created with Matplotlib
